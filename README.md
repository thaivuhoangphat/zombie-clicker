# Zombie Clicker 🧟

A tiny vanilla‑JS clicker game. Click the zombie to score points.  
This repo is prepared to **work with CoderabbitAI** (for AI code reviews) and **deploy to GitHub Pages** automatically.

## Quick Start
1. Open `index.html` in a browser — it runs locally.
2. Or push to GitHub and enable Actions to deploy to GitHub Pages.

## CoderabbitAI (optional but recommended)
- Install the GitHub App “coderabbitai” on this repo.
- Create a Pull Request to trigger the AI review.
- You can mention the bot in a PR comment, e.g.:
  ```
  @coderabbitai summarize this pull request
  @coderabbitai suggest improvements
  @coderabbitai check code style
  ```

## Deploy via GitHub Pages
This repo includes a GitHub Actions workflow that automatically deploys to GitHub Pages on pushes to `main`.
After the first successful run, visit:
```
https://<your-username>.github.io/zombie-clicker/
```
(replace `<your-username>` with your GitHub username).
